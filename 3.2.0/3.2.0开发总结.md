## 二、关键技术决策与踩坑（3.3.0 必读 ⚠️）

### 1. WinForms 事件顺序（× 按钮误删根因，重要）
- **实测事件顺序**：`txt.Leave → btn.GotFocus → btn.MouseDown → btn.Click`
- 输入框的 Leave **先于**按钮的 GotFocus/MouseDown 触发！
- 任何"按钮 GotFocus/MouseDown 里设标志防 Leave 自动取消"的方案都无效（标志设置太晚）
- 正确方案：**Leave 里 BeginInvoke 延迟到消息队列末尾再检查标志**——此时按钮事件已跑完
- 结论：录制中点 × = 只取消不删除；非录制点 × = 删除

### 2. ComboBox 深色边框（下拉框白边根因）
- 系统 ComboBox 自带**经典 3D 凹陷边框**（WS_EX_CLIENTEDGE）：左上白色高光 + 右下灰色阴影
- 仅移除 WS_EX_CLIENTEDGE 不够（ComboBox 自身 WM_PAINT 还会画），需：
  1. SetWindowTheme("","") 禁 Win11 主题
  2. 移除 WS_EX_CLIENTEDGE + SetWindowPos(SWP_FRAMECHANGED) 刷新
  3. WM_PAINT 后**粗笔（4px 背景色）沿圆角路径覆盖系统边框** → Region.Exclude 填四角 → 1px 深色边框
- WM_ERASEBKGND 对系统 ComboBox **不可靠**（WM_PAINT 会重画），必须 WM_PAINT 后覆盖

### 3. 热键 Parse/Format 往返一致性
- HotKeyCaptureBox 显示用 Format(vk, mods)，注册用 Parse(string)
- **两者必须对称**：Format 能输出的字符串 Parse 必须能解析，否则注册静默失败（返回 -1，无提示）
- 已修：NumPad0-9/运算符/OEM 标点/numpadseparator 等全部补齐
- **教训**：新增键位支持必须同时改 Parse 和 Format 两处

### 4. RoundedButton 黑块根因
- `BackColor=Transparent` + SupportsTransparentBackColor 伪透明对自绘控件不可靠（初次绘制/切页重建时四角填充 ARGB(0,0,0) 黑色）
- 正确：不透明 BackColor + OnPaint 先用父背景色 FillRectangle 整个客户区 + 圆角路径填充
- SetParentBackground(color) API 供容器传入背景色

### 5. 模态对话框自动化测试技巧
- BM_CLICK 消息直接触发按钮 Click（比 SendMessage 鼠标消息可靠）
- MessageBox：EnumWindows/EnumChildWindows 找 "是(&Y)" 或 GetDlgItem(dlg, 6=Yes/1=OK) + BM_CLICK
- FindWindow 传中文标题在 PowerShell Add-Type 场景易出问题，用 EnumWindows + GetWindowText 匹配
- BM_CLICK 触发模态对话框后 PowerShell 后续行会被 SIGKILL → **分段执行**
