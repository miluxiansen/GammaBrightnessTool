
## 2026-08-09 10:20 亮度无法保持根因确认：LightBulb 冲突

**现象**：滚轮/右键挡位/左键滑块调亮度后，"变暗一下立刻变亮"，亮度无法保持。3.0.0 绿色版同样复现。

**根因**：用户后台运行的 LightBulb（蓝光/亮度调节软件）在周期性覆写 gamma ramp（其亮度设置为 100%），与 GammaBrightnessTool 冲突，把工具应用的亮度顶回 100%。

**排查历程**（方向多次跑偏，教训深刻）：
1. 09:44-09:47 删 Monitor.SetGamma 随机噪声 workaround（为修 0% 临界闪烁：噪声把峰值 32767 顶到 32768 触发驱动拒绝回退 100%）→ 用 double 计算 BuildGammaRamp 修 0% 边界 → 已出 0947
2. 09:50-10:02 驱动下限实测：本机驱动拒绝 <50% 物理峰值，45%/40% 拒绝但保持 50%，35% 以下拒绝且回退 ~99% → 误判为闪烁根因；写 gamma-diag 诊断程序（枚举显示器+逐 DC 下限+双 DC 交叉验证）
3. 09:52 改 BuildGammaRamp 为二次曲线映射（UI 40% → 物理 58%）→ **用户 09:57 澄清"不是百分比映射问题"，已回退线性**
